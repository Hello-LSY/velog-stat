### 로컬 사용법

#### 프로젝트 클론
```
git clone https://github.com/Hello-LSY/velog-stat.git
cd velog-stat
```

#### 가상환경 생성 및 활성화
```
python -m venv venv
.\venv\Scripts\activate  # Windows
source venv/bin/activate  # macOS/Linux
```

#### 패키지 설치
```
pip install -r requirements.txt
```

#### 실행
```
streamlit run velog_stat\app.py
```
